# 启蒙运动

## 人物与观点
- 洛克：经验论，《政府论》（1689）的同意与财产权。
- 孟德斯鸠《论法的精神》（1748）：权力分立。
- 休谟：归纳问题、因果是习惯、是与应该的区分，苏格兰启蒙。
- 伏尔泰：宗教宽容和对教会的批判。
- 狄德罗与达朗贝尔《百科全书》（1751 至 1772）：把手工技艺和机械纳入知识，这对工程史很重要。
- 卢梭：《论人类不平等的起源》（1755）认为文明和财产带来不平等；《社会契约论》（1762）的公意。
- 亚当·斯密：《道德情感论》（1759）讲同情；《国富论》（1776）用制针工场说明分工，第五篇也写到重复劳动会让工人变得愚钝，并主张公共教育。
- 康德：《纯粹理性批判》（1781）；《何为启蒙》（1784）说启蒙是摆脱自我招致的不成熟，敢于运用自己的理智。
- 孔多塞：对人类无限进步的信念，写于法国大革命恐怖时期躲藏之中。
- 沃斯通克拉夫特《女权辩护》（1792）把理性和权利的逻辑推到女性身上。

## 共同主题
理性批判、宗教宽容、自然权利、科学方法、公共讨论、进步。

## 张力和批评
- 启蒙时期的普遍人权与同时存在的奴隶制和殖民主义之间的矛盾，部分启蒙作家本身有种族等级观念，也有人批判奴隶制。
- 伯克《法国革命论》（1790）：抽象理性不能取代传统和审慎。
- 霍克海默和阿多诺《启蒙辩证法》（1947）：工具理性可以转向支配。
- 浪漫主义和赫尔德：反对单一普遍标准。
- 也不能把启蒙看成一个统一的学派：英、法、苏格兰、德国差异很大。
