Carnot 是常驻桌面的 AI 助手，可以语音唤醒，也可以打字。

安装程序会：
- 把 Carnot 放进"应用程序"，并设为开机自启
- 把语音服务和语音模型放进你的用户资料库
- 如果装了 VS Code，自动加入 Carnot 插件
- 如果还没有 Claude Code，从官方地址下载安装（需要联网）

装完 Carnot 会自动打开。请允许麦克风和屏幕与系统录音，然后退出再打开一次。
要使用 AI，需要登录 Claude 等服务的账号，或填写 API Key，指令和文件会发给你选的服务。

已经装过 Carnot 的话，直接运行这个安装包就会更新，不用卸载，设置、登录和对话都会保留。VS Code 需要重新加载窗口。

需要 Apple 芯片的 Mac 和 macOS 14 以上。
